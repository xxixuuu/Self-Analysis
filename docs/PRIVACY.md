# LifeMetrics プライバシーポリシー

最終更新日: 2024年

## 概要

LifeMetricsは、**プライバシーファースト**を最優先原則とするオープンソースの自己分析ツールです。
あなたのデータは100%ローカルに保存され、外部サービスに送信されることは一切ありません。

## データ収集と保存

### 収集するデータ

LifeMetricsは、あなたが接続を許可したサービスからのみデータを収集します：

- **GitHub**: コミット、PR、Issue、スター履歴
- **Twitter/X**: ツイート、いいね、リツイート
- **Gmail**: メール送受信履歴、ラベル情報
- **Google Calendar**: イベント、予定
- **Slack**: メッセージ、リアクション
- **Spotify**: 再生履歴
- **その他**: 接続を許可したサービス

### データの保存場所

すべてのデータは**あなたのローカルマシン**に保存されます：

- **PostgreSQL**: 構造化データ
- **MinIO**: ファイル・添付ファイル
- **Redis**: 一時キャッシュ

**重要**: データは外部サーバーやクラウドに送信されません。

## AI分析とプライバシー

### Ollama (ローカルLLM)

LifeMetricsは**Ollama**を使用してAI分析を実行します：

- ✅ **完全ローカル実行**: LLMはあなたのマシン上で動作
- ✅ **外部API不要**: OpenAI、Anthropic等の外部サービス不使用
- ✅ **データ送信ゼロ**: 分析データが外部に送信されることはありません
- ✅ **オフライン動作**: インターネット接続不要（データ収集時を除く）

使用可能なモデル：
- llama3.2
- mistral
- gemma2

## データアクセス権限

### OAuth2認証

外部サービスとの接続には、各サービスのOAuth2認証を使用します：

- **最小権限の原則**: 必要最低限の権限のみをリクエスト
- **暗号化保存**: アクセストークンはAES-256-GCMで暗号化
- **リフレッシュトークン**: 自動更新で再認証を最小化
- **接続解除**: いつでもデータソース接続を解除可能

### 要求する権限

各サービスで要求する権限：

**GitHub**:
- `repo`: プライベートリポジトリのコミット情報
- `read:user`: ユーザープロファイル

**Google**:
- `gmail.readonly`: メール読み取り専用
- `calendar.readonly`: カレンダー読み取り専用

**Twitter**:
- `tweet.read`: ツイート読み取り
- `users.read`: ユーザー情報読み取り

## データセキュリティ

### 暗号化

LifeMetricsは多層的な暗号化を採用しています：

1. **At Rest (保存時)**:
   - PostgreSQL: 透過的データ暗号化 (TDE)
   - OAuth Token: AES-256-GCM
   - 機密フィールド: SQLAlchemy暗号化カラム

2. **In Transit (通信時)**:
   - HTTPS (本番環境)
   - コンテナ間通信: 内部ネットワーク

3. **Backup**:
   - gpg暗号化バックアップ

### アクセス制御

- **JWT認証**: すべてのAPI呼び出しに認証が必要
- **監査ログ**: すべてのアクセスを記録
- **セッション管理**: タイムアウト付きセッション

## GDPR準拠

LifeMetricsはGDPR（EU一般データ保護規則）に準拠しています：

### 1. データポータビリティ権

```bash
# すべてのデータをJSON形式でエクスポート
curl -X GET http://localhost:8000/api/export/all \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -o my_data.json
```

### 2. 削除権（忘れられる権利）

```bash
# すべてのデータを削除
curl -X DELETE http://localhost:8000/api/user/delete-all \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 3. アクセス権

- すべての収集データにアクセス可能
- 処理活動の透明性
- データソースの確認

### 4. 修正権

- 誤ったデータの修正
- データの更新

### 5. データ最小化

- 必要最低限のデータのみ収集
- 不要なデータの自動削除

## データ保持期間

デフォルト設定：

- **通常データ**: 365日間保持
- **古いデータ**: 自動削除（設定可能）
- **匿名化**: オプションで古いデータを匿名化

設定変更：

```bash
# .envファイルで設定
DATA_RETENTION_DAYS=365
ANONYMIZE_OLD_DATA=false
```

## データ共有

LifeMetricsは**データを第三者と共有しません**：

- ❌ 外部サービスへの送信なし
- ❌ アナリティクス・トラッキングなし
- ❌ 広告なし
- ❌ データ販売なし

## 監査とロギング

### アクセスログ

すべてのデータアクセスが記録されます：

- アクセス日時
- IPアドレス
- 実行されたアクション
- リソースタイプ

### ログの確認

```bash
# 監査ログの確認
docker exec -it lifemetrics-backend python -m app.scripts.view_audit_log
```

## セキュリティベストプラクティス

### 推奨設定

1. **強力なパスワード**: 12文字以上、記号・数字を含む
2. **定期的なバックアップ**: 週次バックアップを推奨
3. **アクセス制限**: ファイアウォールでポートを保護
4. **定期的な更新**: セキュリティパッチの適用

### ローカルネットワークのみで使用

```yaml
# docker-compose.yml
services:
  backend:
    ports:
      - "127.0.0.1:8000:8000"  # ローカルホストのみ
  frontend:
    ports:
      - "127.0.0.1:3000:3000"  # ローカルホストのみ
```

## インシデント対応

### データ漏洩の可能性

セルフホスト環境のため、データ漏洩のリスクは極めて低いですが：

1. **即座にサービス停止**: `docker-compose down`
2. **ログの確認**: 不正アクセスの痕跡を確認
3. **パスワード変更**: すべての認証情報を変更
4. **再インストール**: クリーンな環境で再構築
